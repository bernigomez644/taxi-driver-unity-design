# Taxi Driver · Design phase

> **The finished game lives in [taxi-driver-unity](https://github.com/bernigomez644/taxi-driver-unity).**
> This repository is kept as an archive of the first deliverable.

Part 1 of the final project of the *Paradigmas y Técnicas de Programación* course (Universidad Pontificia
Comillas, ICAI, 2024). Before writing the game, the team designed its architecture:

- **Design patterns** chosen and why: Singleton, Observer, State, Strategy and Factory.
- **User stories** for the three actors: the taxi driver (player), the police and the passengers.
- **UML class diagram** of the planned system.
- First prototypes of the taxi and police-car prefabs and controllers in Unity.
